# 🎓 Campus Mobile

Plataforma universitaria multiplataforma desarrollada para centralizar diferentes servicios y funcionalidades académicas en una sola aplicación.

El proyecto cuenta con una aplicación móvil, una interfaz web y un backend encargado de gestionar la lógica de negocio y la comunicación con la base de datos.

## 🚀 Tecnologías

### 📱 Mobile

- React Native
- Expo
- TypeScript
- Expo Router
- React Navigation
- AsyncStorage

### 🌐 Web

- React
- JavaScript
- HTML
- CSS

### ⚙️ Backend

- Node.js
- Express.js
- Sequelize
- MySQL
- CORS
- dotenv
